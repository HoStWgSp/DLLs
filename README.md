Класс User при инициализации проверяет существование таблицы Users.
Если ее не существует, то создает ее.
Далее работа с объектом класса User включает в себя следующие функции:
1. **UserAuthorization** с аргументом. Если true, то на форму будет добавлена ссылка на регистрацию.
   После входа возвращает Dictionary<strinf, string> с данными авторизованного пользовател, иначе возвращает пустой Dictionary.
2. **AddNewUser**. Последобавления нового пользователя в таблицу Users. Возвращает Dictionary<strinf, string> добавленного пользователя.
